Preview. This is the real SHAIP web app with its real account server, both running inside this browser tab (the server is the same Go code, compiled to WebAssembly). Accounts and devices you create here live only in this tab and are gone when you reload it; nothing is sent anywhere. Connecting to the VPN happens in the iPhone app or the shaip command-line client, and no payment wallet is connected, so neither is part of this preview.
